# PartGLEE＋Valen 迁移验证

代码、配置、tokenizer、字体和基础权重已集中到 `AffordanceJEV`。**现有 Conda 环境未迁移、未修改包版本。** Git 排除权重、数据集和实验输出；新主机按 [README](../README.md) 补齐资源。

## 已验证

在另一目录实际 Git clone，补入权重与三个 RGB 样例；重新编译 CUDA 扩展，以空 Hugging Face 缓存、离线模式运行。使用当前外部 Conda 环境和 RTX 4090。

| 检查 | 结果 |
|---|---|
| 原始 Valen：杯子、长柄勺、锯各 1 张 | 原始候选、前景、整理后候选、三张输入图、prompt、类别概率和最终 mask 与迁移前完全一致 |
| B0、C1：同三张图，各 3 次预测 | prompt、类别概率和最终 mask 与迁移前完全一致 |
| `infer.sh`：单张纯 RGB＋B0 | 完整运行；没有提供 GT；输入图、prompt、概率和 mask 与原 B0 样例完全一致 |
| 固定 76 张训练清单重建 | 与原清单 SHA256 一致；76 个 RGB/MAT 校验通过；训练／测试无重叠 |
| 训练输入重建 | 保留 76 张图及原多数类别监督，未增加训练帧 |
| 环境、权重和扩展 | 两环境检查通过；基础资源及 B0 SHA256 校验通过；两项 CUDA 扩展编译成功 |
| 既有单元测试 | 25 项通过 |
| GT 多数类别界面 | 2,661 张、13,122 个候选逐一核对；复算 mIoU **81.95%**、gIoU **75.49%**；浏览器交互检查通过 |

本次验证覆盖迁移后的执行与样例一致性，**未重新训练、未重跑全量模型评测，也未在全新 Conda 环境完成安装测试**。新主机的 GPU、驱动或库版本变化可能带来浮点差异。
