# 实验文档撰写

本 Skill 记录用户偏好的实验文档写法，包含**实验计划**和**实验结果**两部分。目标是让读者快速看清研究安排、实验联系和实际结果，同时保留理解方法所必需的说明。

沿用用户或现有文档的语言、位置和格式，不预设项目、模型、数据集、指标或方法名称。编写文档本身不授权启动实验、修改配置或发布内容。

## 共同原则

- **表格便于总览，分类说明负责解释。** 简洁不等于只剩实验名称和状态；读者应能看懂每组实验解决什么问题、为何比较、彼此怎样关联。
- 保留已有且合理的按方法或目的分组。根据实际工作组织内容，不强行套用固定分类、实验数量或编号。
- 共用条件集中说明，特殊条件写在对应组。避免逐行复述表格、记录操作流水、堆叠术语和审计链接。
- 只精简文字时，保留现有实验范围、表格数值和有效分类；不因篇幅自行取消实验、改变状态或调整研究安排。
- 详细命令、推导、配置和日志用少量相关链接承接。用户已认可的内容丰富程度，优先作为本次修改的尺度。

## 一、实验计划

### 开头给出状态总表

默认列为：**类别｜实验｜对照关系／验证目的｜状态**；按实际内容调整，避免把实现细节挤进表格。

- 状态以已有记录为依据，通常使用“已完成／进行中／未开展”；状态无法确认时注明“待核实”。
- 区分方案写完、代码就绪、实验运行和完整评测完成，不能用“已规划”或“已启动”冒充“已完成”。
- 拆开状态不同或对照目的不同的实验；不要把一组部分完成的工作整体标成已完成。
- 总表用于展示整体安排。详细指标放在结果文档，必要时提供入口。

### 按研究目的分类展开

总表之后保留简短的分类说明，例如基础对照、输入或提示改进、监督训练、机制消融、组合验证、泛化与效率验证；只使用当前项目需要的类别。

每组先说明研究问题，再用短段落或列表回答：

- **做什么**：具体改变哪个环节、输入或训练机制。
- **和谁比**：共同基线或配对对照是什么，哪些条件保持相同。
- **验证什么**：这组对比能支持哪项判断，是否仍混合了多个因素。

缩写、方法代号和关键机制在首次出现时解释。保持能理解实验设计的粒度，不展开成实现手册；也不要只留下“做增强／加一致性”等无法辨认差异的短语。

### 说明实验之间的联系

- 区分**共同基线、并行探索、成对消融、前序依赖和后续组合**。有必要时用一小段关系说明或简短 Mermaid 图。
- 同组对照要说明新增因素，例如“仅增强”对比“增强＋约束”；不能只列方法代号，让读者自己猜。
- 说明箭头代表实验对照还是实际执行顺序，避免把独立训练误画成依次继承权重。
- 明确单项机制验证与组合方法验证的区别。尚未做的组合不能写成已有方法或确定收益。

### 保留必要条件与当前范围

集中交代会影响解释的评测范围、资源或训练预算、模型选择方式和共享条件；有预算差异就说明。概览不需要枚举所有超参数。

区分当前执行项与后续储备；不要把储备清单写成全部立即开展的承诺，也不因撰写计划自动增加交叉验证、参数搜索或额外评测。用户明确取消的方案不要混回待办。

**计划完成检查**：读者能否从总表看状态，从分类说明理解方法，再说清每个实验与谁比较、为何有必要？如果只能看到实验清单，说明精简过度。

## 二、实验结果

### 以分组结果表格为主体

- 开头简要交代实验对象、评测范围和共同条件。不同目的或不同评价条件的结果分组，不强行混成一个大表，也不按指标拆散方法对照。
- 每组以结果表格为主体；分项结果、效率和资源开销确有价值时再附表。比较对象及其使用的额外数据或资源应能辨认。
- 每组保留简短的核心结论，加上理解方法差异所必需的说明。表中已有的数据无需逐行复述，不重复计划中的完整方法介绍。
- 保留少量直接相关的入口，例如可视化、完整指标或配置。详细过程留在来源文件，不为缩短文字隐去影响可比性的条件。

### 依据实际结果更新

- 从原始指标、统计输出或实验记录取值，并确认完成状态；进行中、部分完成或失败的实验不能写成完整成绩。
- 新增方法放入对应方法组，并补齐已有且相关的分项表。没有测量的字段写 `—` 或沿用现有缺失标记，不估计或挪用其他方案的数据。
- 仅精简时不重算、替换或删除成绩。发现矛盾先核对来源，无法确认就明确标记。
- 核对原有数据、表格对齐、单位及链接。自动生成器不能覆盖用户已认可的文档结构和精简版式。

### 保持可比性与指标含义

- 比较前核对样本范围、测量方法、统计口径和实验条件。条件不同则分表或用短注说明，不直接合并排名。
- 保留足以影响结论的资源、预算、处理流程和选择策略差异；某一条件相同，不代表实验成本或设置完全相同。
- 沿用领域与原表的合理精度，统一同列单位，标明指标优劣方向。差值从未四舍五入的数据计算；百分比的绝对差使用“百分点”，与相对变化率区分。
- 不替换指标含义，不把代理指标等同于最终任务表现。已有详细定义时，汇总仅保留必要的短注。
- 时间、吞吐量和资源开销必须有可比的统计范围。例如单步骤与完整流程、单样本与整批任务不能直接混比；共用硬件、预热、加载等条件集中说明。
- 理想条件、使用参考答案的诊断、理论界限和正常实验结果应明确区分，不混作实际方法成绩。
- 重复次数不足、样本曾用于方法开发、测量波动等会影响解释的事实，用短注保留；没有统计证据时，不把小幅变化写成确定的改进。

## 两份文档的协同检查

- 计划回答“做哪些、为什么、如何对照、做到哪里”；结果回答“测得怎样、差异多大、比较条件是什么”。两者互相链接，不重复堆放相同内容。
- 同一实验的方法名称、范围和状态是否一致？完整结果落地后，更新涉及的计划状态；明确说明部分完成的范围。
- 结果表是否有来源、单位和必要限制？计划是否有足够说明，能够看出实验联系？
- 链接是否相对目标文档正确？是否误改了实验代码、配置或无关文档？

不设置固定篇幅、精简比例、表格数量或方法名单。以读者能理解研究安排和实际结论为准，不追求最短文档。
